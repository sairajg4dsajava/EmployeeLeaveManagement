# Employee Leave Management System

## Project Description
Employee Leave Management System is a Java JDBC project used to manage employee leave requests digitally.

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Modules
1. Employee Registration
2. Employee Login
3. Apply Leave
4. Approve Leave

## Database Tables
- employees
- leave_requests

## CRUD Operations
- CREATE
- READ
- UPDATE
