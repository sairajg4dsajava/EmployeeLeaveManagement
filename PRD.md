# Product Requirement Document (PRD)

# Project Name
Employee Leave Management System

# Problem Statement
Managing employee leave manually using papers or spreadsheets is time-consuming and difficult to maintain.

# Solution
The Employee Leave Management System helps employees apply for leave digitally and helps managers approve or reject leave requests efficiently.

# Objective
- Automate leave management process
- Reduce manual paperwork
- Maintain centralized employee leave records
- Improve leave tracking efficiency

# Target Users
- Employees
- Managers
- HR Department

# Modules

## 1. Employee Registration
Employees can register into the system using personal details.

## 2. Employee Login
Employees can log in securely using email and password.

## 3. Apply Leave
Employees can apply for leave by selecting leave type and dates.

## 4. Approve Leave
Managers can approve or reject employee leave requests.

# Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA
- GitHub

# Benefits
- Saves time
- Easy leave tracking
- Reduces paperwork
- Improves management efficiency
